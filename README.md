# 🚀 Aegon

### Linux-Native C++26 Asynchronous Web Framework

**[github.com/UdayKhare09/Aegon](https://github.com/UdayKhare09/Aegon)**

Aegon is a high-performance Linux-native web framework built around modern C++ and Linux kernel capabilities.

The project explores how far a web server can be pushed by taking advantage of modern kernel and language features instead of hiding them behind layers of abstraction.

The framework uses technologies such as:

`C++26` · `io_uring` · `Coroutines` · `HTTP/1.1` · `HTTP/2` · `HTTP/3` · `QUIC` · `WebSocket` · `SIMD`

**[Benchmark Results →](https://github.com/UdayKhare09/Aegon/blob/main/benchmarks/httparena_results.md)**

**[Aegon →](https://github.com/UdayKhare09/Aegon)**
